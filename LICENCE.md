## 🧩 About

**Grim Dawn Companion** is a curated list of Grim Dawn open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot filter overlay, stat viewer
- **Quality-of-Life Helpers** — stash organizer, build planner notes, overlay notes
- **Research Notes** — farming routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- Loot Filter Overlay — highlight useful drops on screen
- Stat Viewer — read-only breakdown of character stats
- Damage Notes — record and review damage logs
- Game Speed Slider — adjust single-player pace for study (0.5x to 3x)

### 🎒 Inventory & Stash
- Stash Organizer — group components and materials
- Component Catalog — browse crafting components and relic notes
- Build Planner Notes — organize skill and devotion layouts

### 🗺️ World & Loot
- Loot overlay Notes — mark farming spots on the map
- Waypoint Notes — annotate routes across Cairn
- Boss Log — track farming runs for review
